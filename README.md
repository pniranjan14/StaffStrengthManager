# Staff Strength Manager 🏢📊

A full-stack web application designed for tracking and managing office-wise staff strength, designations, transfers, and promotions.

## ✨ Features
- 👥 **Staff Management:** Add, edit, transfer, and promote staff across different offices and designations.
- 📁 **Excel Data Import:** Upload and parse Excel spreadsheets to update office staff records in bulk.
- 🔐 **Authentication & RBAC:** JWT authentication with role-based access control (Admin & User roles).
- 📊 **Dashboard & Summaries:** Real-time summary cards and statistics on staff distribution.
- ⚡ **Tech Stack:**
  - **Frontend:** React, Vite, TailwindCSS / CSS
  - **Backend:** Node.js, Express.js
  - **Database:** SQLite (`better-sqlite3`)
